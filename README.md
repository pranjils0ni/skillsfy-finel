# 🏛️ Skillsfy - Institute of Technology

> **Build Skills for the future that matter.**  
> Official web platform, learning management system (LMS), 25% affiliate portal, and multi-user admissions CRM for **Skillsfy - Institute of Technology** (Jabalpur Flagship Center & Online Cohorts).

---

## 🚀 Key Features

- **Flagship Program:** *Skillsfy Standard Course: AI + Digital Business Masterclass* (14 AI Modules, 3 Exclusive Bonuses worth ₹17,000 FREE, ₹2,999 offer price).
- **25% Affiliate Portal:** Earn ₹750 per standard course referral, unique referral tracking link, live clicks/earnings counter, and direct UPI/Bank withdrawals.
- **Multi-User Teams CRM:** Super Admin, Lead Counselors, Operations Dispatcher, and Affiliate Finance Manager with 1-click WhatsApp chat triggers.
- **Student LMS & Video Classroom:** In-browser GPU Code Sandbox, lecture notes scratchpad, and interactive knowledge check quizzes.
- **Verifiable Certificates:** QR-code enabled cryptographic validation registry.
- **Developer Panel:** Live injection of Meta Pixel ID, Google Analytics GA4, and Make/Zapier Webhooks.

## 🛠️ Getting Started Locally

Open any static web server or run via PowerShell:


Visit: `http://localhost:3000/index.html`
